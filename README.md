# 雾界回响 · Mist / Echo

古风像素对战游戏原型。穿过竹海、月庭与云上祭坛，听见你的回响。

[开始游玩](https://Yejidaxue.github.io/mist-echo-brawl/)

## 游玩

使用电脑浏览器，点击“开始游戏”，选择场景和模式，观看或跳过序章。引擎载入完成后点击“进入战场”。

P1：A/D移动、W跳跃、S防御、左Shift冲刺、F/G/H/J/K攻击。

P2：方向键、右Shift冲刺、小键盘1/2/4/5/6；也可用 / . , ; ' 。

Esc暂停/继续，R重开。第一次游玩建议选择“自由训练”。音乐在第一次点击后启用，可随时关闭。当前版本推荐电脑键盘，不含触屏虚拟按键。

## 版本内容

- 三张由Gemini按项目提示生成的像素风背景。
- 古风开始UI、三景选择、三种模式、中文字体。
- 14秒可跳过开场动画、48秒原创循环音乐。
- Unity 6000.6.4f1 WebGL Release、固定60Hz战斗核心、88帧角色切片。
- 14项EditMode和9项PlayMode测试通过；浏览器验证移动、攻击、跳跃、暂停、返回与有声重复开局。

## 发布结构

game-web.zip 是已构建的静态游戏发布包。GitHub Actions仅将其解压并发布到Pages，不在云端运行Unity或处理账户信息。发布站点包含完整的媒体来源说明和字体许可。

原创代码、界面和合成音乐采用MIT许可。角色与部分音效为CC0；Noto Serif SC为SIL OFL；背景标记为Gemini生成，详见THIRD_PARTY_NOTICES.md。Unity引擎不适用项目的MIT许可。
